# 应援滚动屏

把手机变成应援灯牌的工具：输入一句话，文字即以全屏黑底白字横向滚动，适合演唱会、机场接机等应援场景。

## ✨ 功能特性

- 输入任意文字（最多 50 字）一键开始，内置「我爱你」「辛苦了」等快捷短语
- 竖屏持机时舞台自动旋转 90°，让文字始终沿屏幕长边滚动；旋转 / 缩放时自动重排
- 无缝循环补位：按滚动区宽度生成文字副本，短文字也不会右侧露空
- 速度、字号滑杆实时调节，字号上限自动跟随屏幕短边（拉满即撑满屏幕）
- 进入时自动全屏并尝试锁定横屏，Wake Lock 保持屏幕常亮，并提醒手动拉满亮度
- 控制界面 4 秒无操作自动隐藏，点击屏幕空白处可唤出 / 隐藏

## 🚀 使用方法

纯静态单文件页面，无需构建、无需联网。直接用浏览器打开 `index.html`（建议在手机浏览器中打开并添加到主屏使用）。

## 🛠️ 技术栈

- 纯 HTML / CSS / JavaScript（单文件，零依赖）
- Web API：`requestAnimationFrame` 动画、Fullscreen API、Screen Wake Lock API、Screen Orientation API

## 📁 目录结构

- `index.html` — 输入页与滚动屏的全部界面和逻辑
